# CP932とUNICODEの一対一の対応表

CP932とUnicodeの一対一の対応表です。

CP932内には、複数のCP932コードが同じ文字に対応する文字があります。そのため、CP932からUnicodeへの変換は成立しますが、UnicodeからCP932への変換において、一部の文字については2つ以上の候補があるため、CP932コードを確定できません。

本表では、bestfit932.txt に基づき、UnicodeからCP932への変換先を確定しています。

なお、CP932 1バイト部に対応したUnicode(半角英数字記号0x20-0x7eの95文字、半角カナ0xA1-0xDFの63文字、計158文字)、および CP932 2バイト部に対応したUnicode(7326文字)、計7484文字が対象です。

## 構造

データは**タブ区切り**です。

| 項目 |
|---|
| CP932の文字コード |
| Unicodeコードポイント |
| UnicodeをUTF-8で表したコード |
| 実際の文字 |
| Unicode文字名 |
| 東アジアの文字幅特性 |
| 文字幅（1または2） |

## 文字幅

`文字幅` は、日本語環境下における一般的な表示幅を示します。

- `1` : ASCII、半角カナなど
- `2` : 上記以外の文字
