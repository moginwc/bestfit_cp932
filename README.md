# CP932とUNICODEの一対一の対応表

CP932とUnicodeの一対一の対応関係をまとめたデータです。

## 構造

データは**タブ区切り（TSV）**です。

| 項目 |
|---|
| CP932の文字コード |
| Unicodeコードポイント |
| UnicodeをUTF-8で表したコード |
| 実際の文字 |
| Unicode文字名 |
| 東アジアの文字幅特性 |
| 文字幅（1または2） |

## 文字幅

`文字幅` は、日本語環境下における一般的な表示幅を示します。

- `1` : ASCII、半角カナなど
- `2` : 上記以外の文字
